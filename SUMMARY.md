## 📝 INSTRUCTIONS D'UTILISATION

### 1. Démarrage Immédiat
```bash
cd mon_portfolio
npm install
npm run dev
```
Ouvrir http://localhost:5173

### 2. Personnalisation
Modifier `src/data.js` avec vos informations :
- Nom, rôle, bio
- Email, téléphone, localisation
- Liens GitHub, LinkedIn
- Compétences et niveaux
- Projets avec technologies
- Formation et dates

### 3. Couleurs
Modifier `tailwind.config.cjs` :
- Colors > primary
- Colors > accent
- Conserver la structure

### 4. Avatar
Remplacer `src/assets/avatar.svg` par votre image

### 5. Formulaire Contact
Intégrer EmailJS (voir QUICK_START.md)

### 6. Déploiement
```bash
npm run build
# Upload dist/ sur Netlify/Vercel
```
